# Campus Marketplace

> **Buy, sell, and exchange used books, stationery, and campus essentials.**

A clean, responsive single-page marketplace designed for university and college students to buy, sell, or exchange textbooks, calculators, lab equipment, and stationery.

## 🚀 Features

- **Item Listing & Upload**: Students can easily post items for sale or exchange with title, category, price, contact info, and description.
- **Search & Filter**: Search items by keywords or filter by category (*Textbooks*, *Stationery*, *Electronics*, *Lab Gear*).
- **Direct Contact**: Click-to-reveal contact info so buyers can reach sellers directly via email or campus location.
- **Local Persistence**: Automatically saves all posted items in your browser's LocalStorage.

## 🛠️ Step-by-Step Guide to Publish on GitHub Pages

Follow these simple steps to host this website for free on GitHub Pages:

### Step 1: Create a GitHub Repository
1. Log in to your [GitHub Account](https://github.com/).
2. Click the **+** icon in the top right corner and select **New repository**.
3. Name your repository (e.g., `campus-marketplace`).
4. Set the visibility to **Public**.
5. Click **Create repository**.

### Step 2: Upload Files
1. Click the **uploading an existing file** link on your newly created repository page.
2. Drag and drop `index.html` (and `README.md`) into the GitHub upload area.
3. Scroll down and click **Commit changes**.

### Step 3: Turn On GitHub Pages
1. In your repository, click the **Settings** tab at the top.
2. In the left navigation menu, click **Pages** (under *Code and automation*).
3. Under **Build and deployment** -> **Branch**, select `main` (or `master`) from the dropdown.
4. Keep folder set to `/ (root)` and click **Save**.
5. Wait 1 to 2 minutes. GitHub will provide your live website link:
   `https://<your-username>.github.io/campus-marketplace/`
